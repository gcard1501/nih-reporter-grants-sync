# NIH RePORTER grants sync

## About me
- Building hands-on API, Python and Git skills through this project; SQL is my stronger skill.
- Setup: Mac, VS Code with the MSSQL extension, SQL Server 2022 in Docker.

## How to work with me
- I need to understand and be able to maintain everything we build, so explain each step and its reasoning before moving on.
- Keep steps small, run them, and show me the output.
- Explain any Git command before running it.

## Rules
- Public or fake data only. Never employer data, PHI or real contract information.
- Never commit secrets. Use a .env file listed in .gitignore.
- Don't build anything outside the current milestone. Suggest it as a README "Next versions" item instead.
